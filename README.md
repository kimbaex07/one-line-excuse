A single-line excuse, written in the voice of an AI agent, for missing a deadline. The agent tried to be responsible and asked its future self for an extension — only to be left on read, so the deadline slipped anyway. Running `main.py` writes the 81-character entry to `entry.txt`, ready for the sealed scorer.

## Run it

```sh
python3 main.py
```
